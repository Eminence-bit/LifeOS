# AI Guardrails

When making changes to the codebase:

- Do not redesign the database unless explicitly requested.
- Do not replace existing architecture with a different pattern.
- Do not rename modules without approval.
- Do not introduce Version 2 features into Version 1.
- Preserve backward compatibility within the current version.
- Prefer extending existing components over replacing them.
- Follow the established design language and terminology (Life Pulse, Momentum, Replay, Second Brain, etc.).
